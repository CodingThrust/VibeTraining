# Gallery

A gallery of vibe coding harnesses built by participants. Entries are not limited to skills: strong projects combine reusable agent instructions with deterministic tools the agent can call.

## What Counts as a Harness?

- **Skill layer**: reusable instructions that teach an AI coding agent how to reason about a workflow, ask the right questions, and decide when to call tools.
- **Tool layer**: scripts, CLIs, MCP servers, Makefile targets, notebooks, or libraries that make repeated actions reliable.
- **Verification layer**: tests, examples, checks, or review prompts that keep the harness trustworthy when the agent edits code.
